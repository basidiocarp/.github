# Basidiocarp

A suite of AI coding agent infrastructure tools for building autonomous development workflows.

## Tools

| Tool | Description |
|------|-------------|
| **mycelium** | Token-optimized CLI proxy — filters command output before reaching the model |
| **hyphae** | Persistent memory and RAG — stores memories, memoirs, sessions, and indexed documents |
| **rhizome** | Code intelligence MCP server — provides structure-aware code navigation and editing |
| **cortina** | Lifecycle signal runner — captures hook events and writes structured signals |
| **lamella** | Skills and plugin packaging — bundles shared content for Claude and Codex |
| **cap** | Dashboard and operator UI — renders ecosystem data and brokers write-through actions |
| **canopy** | Multi-agent coordination — tracks task ownership, handoffs, and evidence |
| **annulus** | Operator utilities — renders terminal surfaces like the statusline |
| **hymenium** | Workflow orchestration — dispatches tasks, gates phases, and handles retry/recovery |
| **volva** | Execution-host runtime — hosts backend orchestration at the runtime seam |
| **spore** | Shared Rust infrastructure — supplies discovery, transport, config, and path primitives |
| **stipe** | Installer and manager — handles install, setup, init, update, and doctor flows |

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/basidiocarp/stipe/main/install.sh | sh
stipe setup
```

For detailed installation and configuration, see the [stipe documentation](https://github.com/basidiocarp/stipe).
